Overview

DeepSec is a single-binary security platform for engineering teams. It scans filesystem, Git repos, container images and URLs with unified reporting. Use locally, in CI, or as a service (deepsec server start, deepsec mcp start for AI agents).

Any Language: Go, Java, JS/TS, Python, Rust, PHP, Ruby, C/C++, C#, Kotlin, Swift
Any Webpage: Marketing, SaaS, APIs, SPAs — deepsec webscan https://any.site
Any Pipeline: Table (human), JSON/SARIF (GitHub), CycloneDX/SPDX (SBOM), HTML (executive)

WebScan — Deep Security Check

deepsec webscan https://example.com performs 20+ OWASP-grade checks:

  • Headers Deep — HSTS max-age/includeSubDomains/preload, CSP unsafe-inline/wildcard, X-Frame-Options, COOP/COEP/CORP
  • TLS Deep — HTTP→HTTPS, TLS <1.2, weak ciphers, cert expiry <30d/7d, self-signed, hostname mismatch
  • Cookie — Secure, HttpOnly, SameSite
  • CORS — wildcard *, reflected Origin, null
  • Disclosure — Server, X-Powered-By, Via
  • Methods — OPTIONS Allow, TRACE/XST
  • Clickjacking — X-Frame-Options / CSP frame-ancestors
  • Exposed Files — /.env /.git/HEAD backup.zip (safe GET)
  • Open Redirect — ?url=//evil.com (safe, no follow)
  • XSS Reflection — safe marker <s>deepsecXSS1337</s>
  • SQLi Error — ' injection (safe)
  • Listing — Index of/ exposure
  • Security.txt & robots.txt — RFC 9116
  • Mixed Content & SRI — http on https, missing integrity
  • HTTPS Redirect — http → https 301
deepsec webscan https://pixelcity.top --severity medium deepsec webscan https://example.com --format sarif --output ws.sarif deepsec scan https://example.com --scanner webscan,dast --format html --output ws.html

Configuration

deepsec init # creates .deepsec.yaml cat .deepsec.yaml
version: "1.0.0" scanners: { sast: true, sca: true, secrets: true, iac: true, container: true, dast: true, webscan: true, network: true, license: true } report: { format: html, color: true } filter: min_severity: low fail_on: HIGH compliance: [soc2, iso27001, gdpr, owasp] exclude_rules: [webscan-missing-security-txt]

CLI overrides: --severity medium --fail-on high --compliance soc2 --profile enterprise --no-color
